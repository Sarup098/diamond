Types of Data

Concept ▾

Data is classified in two ways:

By Nature (Statistical)

  • Qualitative (Categorical) — describes qualities
  • Nominal — no order (gender, color)
  • Ordinal — ordered (small/medium/large)
  • Quantitative (Numerical) — numeric values
  • Discrete — countable (students: 0,1,2…)
  • Continuous — any decimal (height, temp)

By Structure (Technical)

  • Structured — tables, SQL, CSV (rigid schema)
  • Semi-Structured — JSON, XML, HTML (has tags, flexible)
  • Unstructured — images, video, social media, PDFs (no format)

Types of Analytics

Theory ▾

Descriptive

"What happened?"

Summarizes past/current events. Bar charts, reports, dashboards. Eg: Which products sold most last quarter?

Predictive

"What will happen?"

Uses ML/regression to forecast. Eg: Which customers will churn next month?

Prescriptive

"What should we do?"

Most advanced. Recommends optimal action. Eg: Best delivery routes using optimization.

"Why did it happen?"

Examines causes by drilling down — root cause analysis of anomalies in descriptive results.

② MEDIAN (Middle Value)

Formula
Odd n: Median = value at position (n+1)/2
Even n: Median = average of n/2 and (n/2 + 1) positions

Grouped: Median = L + [(n/2 − cf) / f] × h
where L=lower boundary, cf=cumulative freq before, f=freq of median class, h=class width

③ MODE (Most Frequent)

Formula (Grouped)
Mode = L + [f₁ − f₀) / (2f₁ − f₀ − f₂)] × h
where f₁=modal freq, f₀=prev freq, f₂=next freq

For raw data 3,13,11,11,5,4,2 → 11 appears twice → Mode = 11

Variance & Standard Deviation

Formulas ▾
Formulas
Population Variance: σ² = Σ(x − x̄)² / N
Sample Variance: s² = Σ(x − x̄)² / (n−1)
Standard Deviation: σ = √(Variance)

Shortcut: σ² = (Σx²/n) − (x̄)²

Population Variance

  • Uses entire population
  • Denominator: N
  • Exact variability
  • Used in census data

Sample Variance

  • Uses a sample
  • Denominator: n−1 (Bessel's correction)
  • Estimates population variability
  • Used in surveys/experiments
✦ Solved: Variance of 2, 4, 6
1
Mean = (2+4+6)/3 = 4
2
Deviations: (2−4)²=4, (4−4)²=0, (6−4)²=4
3
σ² = (4+0+4)/3 = 8/3 ≈ 2.67
4
σ = √2.67 = 1.63

Correlation & Regression

Exam Paper Q5(b) Formulas ▾
Correlation measures the strength and direction of the linear relationship between two variables.
Regression finds the equation of the best-fit line to predict one variable from another.
Pearson Correlation Coefficient (r)
r = [n·Σxy − Σx·Σy] / √{[n·Σx² − (Σx)²] × [n·Σy² − (Σy)²]}

Range: −1 ≤ r ≤ +1
r = +1 → Perfect positive correlation
r = −1 → Perfect negative correlation
r = 0 → No linear correlation
Linear Regression Line
y = a + bx
b = [n·Σxy − Σx·Σy] / [n·Σx² − (Σx)²]
a = (Σy − b·Σx) / n
Relation between Regression and Correlation:
b = r × (σy / σx) — The regression slope equals correlation × ratio of standard deviations.
r² (coefficient of determination) = proportion of variance in y explained by x.

Probability Distributions

TheoryFormulas ▾

Normal Distribution

Bell-shaped, symmetric. Mean = Median = Mode.
68-95-99.7 Rule:
68% within ±1σ
95% within ±2σ
99.7% within ±3σ

Binomial Distribution

n independent trials, each success prob = p.
P(X=k) = C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ
Mean = np
Variance = np(1−p)

Poisson Distribution

Rare events, P(X=k) = e⁻λ·λᵏ/k!
Mean = λ
Variance = λ
Use when events/time are counted.

Quick Reference — Distributions
Bernoulli: single trial, P(X=1) = p, Mean=p, Var=p(1−p)
Binomial: n trials, Mean=np, Var=np(1−p)
Poisson: rare events, Mean=λ, Var=λ
Exponential: waiting time, Mean=1/λ, Var=1/λ²
Normal: continuous, Mean=μ, Var=σ²

68-95-99.7 Rule (Empirical Rule)

If μ=60, σ=10 (exam scores):
68% score between 50 and 70
95% score between 40 and 80
99.7% score between 30 and 90
Outlier: score < 30 or > 90 is very rare (<0.3%)

Bayes' Theorem

Numericals ▾
Bayes' Formula
P(A|B) = [P(B|A) × P(A)] / P(B)

Where: P(B) = Σ P(B|Aᵢ) × P(Aᵢ) ← Law of Total Probability
✦ Solved: Defective Bulb Problem (from lecture)

3 machines produce bulbs: M1=30%,2% defective | M2=40%,3% | M3=30%,5%
A defective bulb is found. Find probability it came from M1.

1
P(M1)=0.3, P(M2)=0.4, P(M3)=0.3
2
P(D|M1)=0.02, P(D|M2)=0.03, P(D|M3)=0.05
3
P(D) = 0.3×0.02 + 0.4×0.03 + 0.3×0.05 = 0.006+0.012+0.015 = 0.033
4
P(M1|D) = (0.3×0.02)/0.033 = 0.006/0.033 = 0.182 (18.2%)
In Bayes problems: always list Prior probabilities, Likelihoods, compute Total P, then apply formula.

Hypothesis Testing — Z-test, t-test, Chi-Square, ANOVA

FormulasNumericals ▾

Z-Test

Use Z-test when: n ≥ 30 AND population σ is known.
Z-Test Statistic
Z = (x̄ − μ₀) / (σ / √n)

Critical values (two-tailed): α=0.05 → Z_crit = ±1.96
α=0.01 → Z_crit = ±2.576
One-tailed α=0.05: Z_crit = 1.645
✦ Solved: Bulb Lifetime (from lecture)

Claim: μ=500hrs, σ=50, n=36, x̄=520. Test at 5%.

1
H₀: μ=500, H₁: μ≠500 (two-tailed)
2
Z = (520−500)/(50/√36) = 20/(50/6) = 20/8.33 = 2.4
3
Critical Z at 5% two-tailed = ±1.96. Since |2.4| > 1.96 → Reject H₀
4
Conclusion: Avg lifetime IS significantly different from 500hrs at 5% level.

t-Test

Use t-test when: n < 30 OR σ unknown. df = n−1 for one-sample.
t-Test Statistic
One-sample: t = (x̄ − μ₀) / (s / √n) where df = n−1
Two-sample: t = (x̄₁ − x̄₂) / √[sp²(1/n₁ + 1/n₂)]
Paired: t = d̄ / (sd / √n) where d = differences

Chi-Square Test (χ²)

Chi-Square Formula
χ² = Σ [(O − E)² / E]
df = k − 1 (for goodness of fit; k = number of categories)
df = (r−1)(c−1) (for test of independence; r=rows, c=cols)
✦ Solved: Fair Die Test

Die thrown 60 times. Observed: 8,10,9,11,12,10. Is die fair?

1
Expected each face = 60/6 = 10
2
χ² = (8−10)²/10 + (10−10)²/10 + (9−10)²/10 + (11−10)²/10 + (12−10)²/10 + (10−10)²/10
= 0.4+0+0.1+0.1+0.4+0 = 1.0
3
df = 6−1 = 5. Critical χ² at 5% = 11.07
4
1.0 < 11.07 → Accept H₀ → Die is fair

ANOVA (Analysis of Variance)

Use ANOVA to compare means of 3 or more groups simultaneously. One-Way (1 factor), Two-Way (2 factors).
One-Way ANOVA
SSB (Between) = Σnᵢ(x̄ᵢ − x̄_grand)²
SSW (Within) = ΣΣ(xᵢⱼ − x̄ᵢ)²
SST = SSB + SSW
MSB = SSB / (k−1) MSW = SSW / (N−k)
F = MSB / MSW
If F > F_critical → Reject H₀ (groups differ significantly)

Cosine Similarity

Exam Paper Q2(a) Formula ▾
Cosine Similarity measures the cosine of the angle between two vectors. It ranges from −1 to 1 (for non-negative data: 0 to 1). Used to measure how similar two documents/data points are regardless of magnitude.
Formula
cos(θ) = (A · B) / (||A|| × ||B||)

Where: A · B = Σ Aᵢ × Bᵢ (dot product)
||A|| = √(Σ Aᵢ²) (magnitude of A)
||B|| = √(Σ Bᵢ²) (magnitude of B)

Result: 1 = identical direction | 0 = perpendicular | -1 = opposite
✦ Solved Example

A = [1, 2, 3], B = [2, 3, 4]

1
A·B = 1×2 + 2×3 + 3×4 = 2+6+12 = 20
2
||A|| = √(1+4+9) = √14 = 3.742
3
||B|| = √(4+9+16) = √29 = 5.385
4
cos(θ) = 20 / (3.742 × 5.385) = 20 / 20.154 = 0.992 (very similar!)
Application: NLP/text similarity — TF-IDF vectors compared using cosine similarity. Two identical documents → 1. Completely different → ~0.

K-Means Clustering

Exam Paper Q1(a) Python ▾
K-Means Clustering is an unsupervised machine learning algorithm that partitions n data points into k clusters, where each data point belongs to the cluster with the nearest mean (centroid).

Steps of K-Means Algorithm

1
Choose K — decide the number of clusters.
2
Initialize Centroids — randomly select K points as initial centroids.
3
Assign Points — assign each data point to the nearest centroid (using Euclidean distance: d = √Σ(xᵢ−cᵢ)²).
4
Recompute Centroids — compute new centroid as mean of all points in each cluster.
5
Repeat steps 3–4 until centroids stop changing (convergence) or max iterations reached.

Advantages

  • Simple and easy to implement
  • Scales to large datasets
  • Fast convergence
  • Works well for spherical clusters

Disadvantages

  • Must specify K in advance
  • Sensitive to initial centroid placement
  • Affected by outliers
  • Only finds convex/spherical clusters
from sklearn.cluster import KMeans
import numpy as np
import matplotlib.pyplot as plt

# Sample data
X = np.array([[1,2],[1,4],[1,0],[10,2],[10,4],[10,0]])

# Create K-Means with K=2
kmeans = KMeans(n_clusters=2, random_state=0)
kmeans.fit(X)

print("Labels:", kmeans.labels_)         # cluster assignment
print("Centroids:", kmeans.cluster_centers_)

# Plot
plt.scatter(X[:,0], X[:,1], c=kmeans.labels_, cmap='viridis')
plt.scatter(kmeans.cluster_centers_[:,0],
            kmeans.cluster_centers_[:,1], s=200, c='red', marker='X')
plt.show()
The Elbow Method is used to find optimal K: plot inertia (WCSS) vs K and look for the "elbow" point.

Hierarchical Clustering & Dendrogram

Exam Paper Q3(b) Full Solution ▾
Hierarchical Clustering builds a tree of clusters (dendrogram). No need to specify K in advance.
Agglomerative: Bottom-up — start with each point as its own cluster, merge closest pairs.
Divisive: Top-down — start with one cluster, split recursively.

Linkage Methods

Single Linkage

Distance = minimum distance between any two points in the clusters.

Complete Linkage

Distance = maximum distance between any two points in clusters. (Used in Q3(b)!)

Average Linkage

Distance = average of all pairwise distances between clusters.

Association Rule Mining (Apriori)

Exam Paper Q4(a) Full Solution ▾
Association Rule Mining finds interesting relationships/patterns between items in large transactional databases. The classic algorithm is Apriori.
Key Metrics
Support(X) = (Transactions containing X) / (Total transactions)
Confidence(X→Y) = Support(X ∪ Y) / Support(X)
Lift(X→Y) = Confidence(X→Y) / Support(Y)

Lift > 1 → positive association | Lift = 1 → independent | Lift < 1 → negative
★ EXAM Q4(a) FULLY SOLVED — Min Support=50%, Min Confidence=75%

Hadoop Ecosystem

Theory ▾
Apache Hadoop is an open-source framework for distributed storage and processing of large datasets across clusters of computers using simple programming models.

HDFS — Hadoop Distributed File System

  • NameNode — master, stores metadata (file locations)
  • DataNode — workers, store actual data blocks
  • Default block size: 128MB
  • Replication factor: 3 (fault tolerance)
  • Write-once, read-many model
  • Designed for large files, sequential reads

MapReduce

  • Map Phase: Process input → emit (key,value) pairs
  • Shuffle & Sort: Group by key
  • Reduce Phase: Aggregate values per key
  • Example: Word Count — Map outputs (word,1), Reduce sums counts
  • Parallel processing across cluster nodes

HBase

NoSQL database on top of HDFS. Column-oriented. Used for sparse data with billions of rows. Real-time read/write access. Like Google Bigtable.

Hive

Data warehouse system. Uses HiveQL (SQL-like). Converts SQL queries to MapReduce jobs. Best for batch processing, not real-time. Schema-on-read.

Apache Spark

Theory ▾
Apache Spark is a unified analytics engine for large-scale data processing. It is 100× faster than Hadoop MapReduce for in-memory processing and 10× faster for disk operations.

RDD

Resilient Distributed Dataset — core Spark abstraction. Immutable, fault-tolerant, parallelizable.

Spark SQL

SQL interface for structured data. Uses DataFrames and Datasets.

MLlib

Machine learning library — classification, regression, clustering, collaborative filtering.
